# HypeShell Anvil Plugin

This plugin lets HypeShell launch Anvil without moving Anvil platform code into
HypeShell. Install it through HypeRegistry as `hypeAnvil`, or symlink this
directory into `~/.config/HypeShell/plugins/hypeAnvil` while developing.

The plugin exposes launcher actions for opening Anvil, opening the Library view,
installing the dedicated Anvil session, switching back to the greeter, and
refreshing cartridge artwork.

Anvil remains the source of truth for game scanning, artwork, Proton launching,
store/community UX, and the dedicated Wayland session.
